## muesli 0.8.6 preproduction 2

This second preview includes the latest 0.8.6 interface and permission-recovery improvements for upgrade and everyday-use testing before the stable release.

### New in this preview
- Defer permission setup and continue to Timeline. Features explain missing access and take you to Settings → General → Permissions when needed. Voice Notes onboarding can test recording without granting text-pasting access.
- System Audio permission checks support retry and preserve a Grant click made while a background check is running.
- Discover major additions through small New badges that disappear after interaction.
- Read clearer accent-colored actions, open Insights from the Timeline or Dictations statistics tiles, and use the simpler Timeline filter.
- Dismiss individual App Formatting suggestions. Time Turner settings stay compact until capture is enabled.

### Bring your conversations and documents
- Import meeting notes, summaries and transcripts from a Granola ZIP or CSV export. Preview the meetings before importing from Meetings → Import → Granola…
- Chat with saved meetings, follow citations to their source, and attach PDFs, images, Markdown or plain-text documents. Documents stay in their original location; muesli does not keep managed copies. The model can search and read documents as needed.
- New general chats start with no meetings selected. Choose individual meetings or a folder; opening chat within a meeting supplies that meeting's context.
- Use on-device Gemma 4 or your preferred AI provider. Supported local endpoints can use native tool calling with capability detection.

### More ways to write
- Cotypist is now included in preprod and production packages. It stays off until enabled in Settings → Experimental. Complete its input-source setup for on-device suggestions, then press Tab to accept a suggestion or Option + Right Arrow to accept one word. Accepted suggestions appear in your local Timeline with the preceding text and app name.
- With a supported local model, enable “Watch text appear during hands-free mode” in Settings → Dictations. Enabled cleanup runs when you stop.
- Ask Quill a question, follow up, or request an edit to selected text. Configure it in Settings → Experimental.
- Set writing styles, capitalization and final-period preferences per app in Settings → Dictations → App Formatting.

### Find and revisit your work
- Search saved dictations, meetings, chats, writing history and Time Turner screen text from the sidebar or with Command + F.
- Time Turner lets you browse captured screen text and screenshots. Capture is off by default and screen history stays on this Mac. Generating a recap sends sampled text to your selected Meetings provider.
- Record a window or display alongside meeting audio when you choose Record Screen… in the meeting controls. Video stays local and requires Screen Recording permission.

### Models and refinements
- Try Parakeet Redux, Phonon-2.5 and MedASR from Models → Dictation. MedASR requires acceptance of Google's model terms.
- Updated muesli Cleanup Lite and Pro Cleanup — Qwen 3.5 models have an Update action when newer model files are available.
- Saved API keys and supported account credentials migrate to macOS Keychain, with verification before legacy credentials are removed.
- Includes recording-indicator dragging, live-caption, meeting-control and reminder fixes, plus an updated guided What's New tour.

Hosted features send the input and context needed for the request to the selected provider. File references require the originals to remain available.

### Test the update
Keep the older MuesliPreprod installed and choose Check for Updates after the preproduction feed is live. Check installation, relaunch, saved data and credentials, and the What's New tour. MuesliPreprod uses separate local app data; the stable release remains 0.8.5.
