## muesli 0.8.6-preprod.3

- Meet Vidshots: record a window or screen region with spoken narration, then revisit the recording and transcript. Find it in the updated What's New tour.
- Permission setup now guides you through enabling access and restarting muesli, returning to Time Turner setup afterward. Restart checks protect active work and unsent chat drafts.
- Dictate while a meeting is recording, with improvements to meeting titles and summaries.
- Browse meeting people and improve calendar-linked meeting recording and call detection.
- Summary failure logs omit provider error details while keeping useful errors in the app.

This preproduction build is for testing the update from 0.8.6-preprod.2. Check update discovery, installation, relaunch, preserved data and the Vidshots tour card before production release.
